Advanced parameters
CFG override applies a different guidance value during only part of the run. Start/End % are points on the denoising timeline (0 = first step, 1 = last); the override CFG is used only inside that window. The default (3 over 0.90–1.00) lowers guidance for the final 10% of steps to reduce over-sharpening and color burn. Set override = Guidance, or start ≥ end, to disable. The % is a fraction of the step count, so it covers fewer steps in Turbo (12) than Quality (48). Batch size = how many images per render (more = more VRAM and time).
Loads a LoRA from ComfyUI's models/loras/ (the name is the filename, including subfolders). The list autocompletes once you've tested the connection. Only the main diffusion model is patched (model-only); the text encoder and unconditional model are untouched. Leave unchecked to render the base model.
Runs NVIDIA's RTXVideoSuperResolution node on the decoded image before preview/save, scaling it up by the chosen factor. Requires the comfyui_nvidia_rtx_nodes pack and an RTX GPU on the ComfyUI server. Leave unchecked to output at the rendered resolution.

        Vectorizer
        

          
          
          
SAM gives pixel-accurate cutouts but is slow on CPU and can grab the wrong region. The heuristic isolates the “ink” from the local background.

          
          
          
          
Sends the rendered bitmap (downscaled) to the LLM configured above to read each text element — string, font guess, color — and emits real <text> elements instead of traced outlines: tiny, crisp, editable. You confirm what was read before it's used; anything unreadable falls back to tracing. The font name is a best guess — viewers without that font substitute one.

          
          
Asks the same LLM what each element actually contains — flat graphic (vectorize), photographic (keep raster), or clutter (skip) — replacing the flatness heuristic for elements still on “auto”. An explicit per-element vector on/off always wins. All LLM toggles share one call.

          
          
The LLM suggests per-region tracer settings — an exact color palette for flat art (pixels are snapped to it before tracing, so fills come out as clean brand colors instead of dozens of near-duplicates), speckle filtering, color depth, and corner sharpness.

          
          
After vectorizing, shows the LLM the original next to the result and applies its corrections — re-route a region, remove an over-tight clip, fall back from re-typeset text to outlines, relax a palette — then vectorizes once more. Adds a second LLM call and a second trace.
